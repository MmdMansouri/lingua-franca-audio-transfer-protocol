# Timed Audio Transfer Protocol Using Lingua Franca

## Overview

This project focuses on modeling and simulating a timed audio-transfer protocol using the Lingua Franca programming language.

The protocol considers communication between a sender and a receiver operating with asynchronous clocks. The main objective is to model the communication behavior and investigate how clock differences affect reliable data transfer.

## Objectives

Model a timed communication protocol using Lingua Franca.

Design reactive components using the Reactor model.

Represent asynchronous clock behavior.

Model clock drift between sender and receiver.

Simulate protocol execution and analyze its behavior.
